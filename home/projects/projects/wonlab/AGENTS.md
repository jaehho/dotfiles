# wonlab

Agent rules only; the knowledge is the skill in `skill/` (linked as `~/.agents/skills/wonlab` and `~/.claude/skills/wonlab`). Edit it here.

- This file is public (it lives in jaehho/dotfiles); the repo is private. Hosts, addresses and account names go in the skill or issues, never here. Tokens and passwords go nowhere.
- `SKILL.md` holds access rules for every wonlab task; a service's how-to goes in its `skill/references/` file. Dated session logs don't: state lives on the box, and history goes in an issue.
- Tasks, gotchas and decisions are issues in this repo, drafted in `~/projects/writing` like other issue text.
