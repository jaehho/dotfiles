# claude-open lanes: dated history (2026-09-17 to 09-21)

Moved from Claude auto-memory on 2026-09-28. Entries before 2026-09-21 evening use the retired `claude-or`/`claude-mimo` names. Current behavior lives in `home/bin/.local/bin/claude-open`.

## Effort on third-party lanes (2026-09-21)

- `/effort` is real on third-party lanes: Claude Code always puts `output_config.effort` + `thinking:{type:adaptive,display:omitted}` on the wire (stub-observed 2026-09-21; `/effort`, `--effort`, `CLAUDE_CODE_EFFORT_LEVEL`, settings `effortLevel`). z.ai honors it (dose-response: effort=low → 40 out tokens, max → 161). MiMo accepts and ignores it (~77 out tokens at every level). Ollama accepts and ignores (no 400, no real dose-response). OpenRouter maps it (`reasoning.effort` / `output_config.effort` both work); GLM slugs advertise only `max/high/low` (`default_effort=max`), Astra has the full set. If a shim 400s on `output_config.effort`, CC latches `isEffortMarkedUnsupported` and retries without it. The old story "presets are how you set effort on OpenRouter" is false — presets are a shallow-merged request-body convenience, request fields win; `@preset/cc-*` retired 2026-09-21 night.
