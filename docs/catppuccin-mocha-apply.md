# Catppuccin Mocha — GUI apps

Desktop chrome, terminal, and CLI tools are switched via stow. This file covers the GUI apps outside that.

## Stock on purpose

These keep their own default colors. Do not theme them again.

- Firefox Developer Edition: "System theme — auto". Firefox Color was removed 2026-10-29; the "forests of VI" and "Green" themes are still installed but disabled.
- Betterbird: "System theme — auto". The Catppuccin theme was removed 2026-10-29.
- Obsidian (vault `~/Obsidian`): default theme, following the system light/dark setting. The Catppuccin theme was removed 2026-10-29.
- Discord: the official client with no Vencord or BetterDiscord. Vesktop is not installed.
- Google Chrome: its own color setting, no Web Store theme.
- GTK: Adwaita-dark with the dark preference.
- Spotify: stock dark client; spicetify was removed 2026-10-07.

## Kvantum / qt5ct

- Kvantum: theme is stowed to `~/.config/Kvantum/catppuccin-mocha-lavender/` but not selected.
- qt5ct: color scheme `catppuccin-mocha-lavender` is under `~/.config/qt5ct/colors/`; no `qt5ct.conf` selects it.

## No port

visidata, thunar, qalculate, hyprpaper keep defaults.
